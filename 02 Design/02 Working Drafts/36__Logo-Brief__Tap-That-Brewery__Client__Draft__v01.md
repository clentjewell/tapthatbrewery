## Purpose — import and lock, not redesign

Tap That already has a logo that customers recognise — it's on the signage, the tap decals, the glassware and the merch wall. This brief covers **importing the existing marks, completing the variant set, and locking them** so every future asset (website, campaigns, lifecycle emails, white-label collateral) uses identical artwork.

**Redesign is explicitly out of scope.** No redraws, refreshes, "modernisations" or new marks will be produced under this brief unless Tap That requests it in writing. The identity works; the job is consistency.

## 2. Variant set required (per mark, where applicable)

| Variant | Use |
|---|---|
| Full colour (green/gold) on light | Default |
| Full colour on dark / on brand green | Signage, social, menu boards |
| **Mono black** | Print, engraving, one-colour merch |
| **Mono white (inverse)** | Dark grounds, photography overlays, decals |
| **Favicon / social avatar** — TT roundel cropped to square + circle safe area | tapthatbrewery.com.au favicon, @tapthatbreweryandkeghouse avatars, GoTab/receipt contexts |
| Horizontal lockup (if it exists) | Wide formats: web header, email footer |

Plus, defined once and locked: clear-space rule, minimum sizes (print + screen), and incorrect-use examples (no stretching, recolouring, effects, rotation, or badge-on-busy-photo without a contrast device).

## 3. File formats required

| Deliverable | Spec |
|---|---|
| **SVG master** (per mark, per variant) | Vector, curves outlined, the single source of truth |
| **Transparent PNG** | Each variant at 512px, 1024px, 2048px |
| AI/EPS source (as supplied) | Archived unmodified in `02 Design/01 Inputs/` |
| Favicon package | .ico + 32/180/512px PNGs |
| Hex/CMYK/Pantone values | Extracted from source files → feeds 34 Brand Guidelines §2 **[currently TBC]** |

If no vector source exists for any mark, the fallback is a **faithful vector re-trace of the existing artwork** (traced, not redesigned — pixel-faithful to the original), approved by the client against the original before use.

## 4. Trademark / originality check (before lock)

A gate, not a formality — especially given the franchise ambition (10–12 year horizon means the marks must travel):

1. **Ownership** — confirm Tap That owns the artwork outright (original designer's assignment/licence; no stock elements with restricted licences).
2. **Registrability** — IP Australia trade mark search for the name and device marks in classes 32 (beer), 40 (brewing), 43 (taproom services); note any conflicts.
3. **Originality scan** — reverse-image check of badge and roundel against other breweries/keg businesses (the TT monogram and hex-badge forms are common in craft beer; confirm no confusable local mark, including the unverified "Aardvark & Arrow" across the road).
4. Record findings; if a conflict surfaces, that (and only that) reopens a design conversation — client's call.

## 5. Lock criteria (definition of done)

The identity is **locked** when all of the following are true:

- [ ] All three marks received as (or faithfully re-traced to) vector masters, client-verified against in-venue originals
- [ ] Full variant matrix (§2) exported in all formats (§3), filed in `02 Design/03 Final Outputs/`
- [ ] Hex/CMYK values extracted and written into 34 Brand Guidelines (replacing every [TBC])
- [ ] Clear space, minimum sizes and misuse examples documented
- [ ] Trademark/ownership check complete and recorded
- [ ] Client sign-off on this brief's outputs (✍)

After lock: any new application uses these files only; any proposed change to the marks is a new, client-initiated brief.

## What we need from Tap That

1. Original logo files (AI/SVG/EPS preferred; whatever exists otherwise) — badge, roundel, wordmark.
2. Original designer's name/contact and confirmation of IP ownership.
3. Font names used in the wordmark (feeds 34 §3).
4. Any past logo versions still in circulation (so they can be retired deliberately).

## Assumptions & open items

- Mark inventory is photo-derived; source files may reveal additional lockups or reveal that "badge" and "roundel" share one master.
- No trade mark registration status is currently known to Jewell — check assumes none until told otherwise.
- Re-trace fallback is scoped as faithful reproduction only; effort estimate pending sight of source files.
